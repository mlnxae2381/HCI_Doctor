# 네비게이션 테스트 가이드

## ✅ 테스트 시나리오

### 1. 메인 → 분석 페이지 → 메인
**테스트:**
1. 메인 대시보드에서 "CT 분석" 카드 클릭
2. `/analysis/ct` 페이지 이동 확인
3. 상단 헤더 유지 확인 (로고, 네비게이션 표시됨)
4. "← 뒤로가기" 버튼 클릭
5. 메인 대시보드(`/`)로 돌아오는지 확인

**예상 결과:**
- ✅ 헤더가 모든 페이지에서 유지됨
- ✅ 뒤로가기 버튼이 정상 작동
- ✅ 메인으로 정상 복귀

---

### 2. 로고 클릭 테스트
**테스트:**
1. 메인에서 커뮤니티 페이지 이동
2. 상단 좌측 "HCI DocTor" 로고 클릭
3. 메인 대시보드로 돌아오는지 확인

**예상 결과:**
- ✅ 어떤 페이지에서든 로고 클릭 시 메인으로 이동

---

### 3. 커뮤니티 → 피드 → 커뮤니티
**테스트:**
1. 네비게이션에서 "커뮤니티" 클릭
2. 게시글 하나 클릭
3. `/community/feed?id=1` 페이지 이동 확인
4. 게시글 내용 표시 확인
5. "← 뒤로가기" 버튼 클릭
6. `/community`로 돌아오는지 확인

**예상 결과:**
- ✅ 게시글 데이터가 표시됨
- ✅ 뒤로가기로 커뮤니티 목록으로 복귀

---

### 4. 다중 네비게이션 테스트
**테스트:**
1. 메인 → CT 분석 → 메인 (로고 클릭)
2. 메인 → 커뮤니티 → 피드 → 커뮤니티 (뒤로가기)
3. 커뮤니티 → 소개 (네비게이션)
4. 소개 → 메인 (로고 클릭)

**예상 결과:**
- ✅ 모든 경로에서 헤더 유지
- ✅ 브라우저 뒤로가기/앞으로가기 정상 작동
- ✅ URL이 올바르게 변경됨

---

### 5. 브라우저 새로고침 테스트
**테스트:**
1. `/analysis/ct` 페이지에서 F5 새로고침
2. 페이지가 정상적으로 로드되는지 확인
3. 헤더가 표시되는지 확인
4. 뒤로가기 버튼이 작동하는지 확인

**예상 결과:**
- ✅ 새로고침 후에도 페이지 정상 표시
- ✅ Flask가 모든 경로에서 index.html 반환
- ✅ JavaScript 라우터가 올바른 페이지 렌더링

## 🐛 문제 발생 시

### 헤더가 사라지는 경우
**원인:** 페이지가 `container.innerHTML`로 전체를 덮어씀
**해결:** pages.js의 `renderDynamicPage()` 사용 확인

### 뒤로가기가 작동하지 않는 경우
**원인:** 브라우저 히스토리가 올바르게 관리되지 않음
**해결:** `router.navigateTo()` 사용 확인

### 새로고침 시 404
**원인:** Flask가 해당 경로를 index.html로 반환하지 않음
**해결:** app.py의 404 핸들러 확인
